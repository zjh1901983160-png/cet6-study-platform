# 六级专项提升学习平台

单文件网页版（`index.html`，零外部依赖），电脑与手机自适应。

## 页面包含

| 模块 | 内容 |
|---|---|
| 成绩诊断 | 按 389 分（听力 144 / 阅读 138 / 写作翻译 107）自动分析强弱项，给出保底 425、冲刺 500+ 的两段提分路线 |
| 真题精讲 | 6 套真题解析（2023 年 12 月三套、2024 年 6 月三套）：逐题定位、精析、避错，阅读全文中文译文，听力英文原文（可朗读），答案默认隐藏 |
| 词汇学习 | 大纲 5500 词 + 近几年新增词，共 5751 条：音标、释义、真题例句、原文搭配、高频必考/认知词标记，支持分类筛选、记忆模式、懒加载、收藏进生词本。**点音标即可朗读单词** |
| 写作翻译 | 作文五类必背句型、高分词组、3 套带填空的通用模板、避坑清单；翻译固定搭配、五类中国特色词汇、长句拆分/被动/定语模板、中式英语错误 |
| 备考规划 | 十周计划（2026-10-08 起算至 12 月 12 日考试），各题型做题策略 |
| 待复习本 | 真题精讲收藏的题目与生词，本地存储（生词条目可点 🔊 朗读） |
| 云同步 | 多设备共用一份进度：粘贴一次 GitHub 令牌，背词记录、生词本、周计划勾选、成绩、限时刷题记录自动双向同步 |

## 数据来源

- 真题解析：用户提供的 6 套星火英语解析册（2023 年 12 月、2024 年 6 月各三套）
- 词汇：大学英语六级词汇（5500 词，带音标）+ 近几年新增词汇
- 考试时间：2026 年 12 月 12 日 15:00–17:25（教育部教育考试院公告）

解析册不含英文阅读原文与选项文本，因此真题模块采用「精讲」形式；如后续补齐试题册，可升级为限时刷题。

## 说明

页面数据全部内联在 `index.html` 中，进度默认保存在浏览器本地存储。

发音优先使用浏览器内置语音合成；设备没有英文语音包时，退回 `dict.youdao.com` 的在线发音接口（仅此时才会请求网络）。

云同步是可选功能，默认关闭。开启后进度会上传到**你自己 GitHub 账号下的一份私密 gist**（`cet6-progress.json`），平台本身没有服务器，也不接触你的数据：

- 连接方式：在「备考规划 → 云同步」粘贴一次自己生成的 GitHub 令牌（只需 `gist` 权限，链接已预勾选），令牌只存在该设备的浏览器里。
- 同步策略：每个进度项带修改时间，谁最后改的谁生效，不会整包互相覆盖；本机改动 2.5 秒后自动上传，打开页面 / 切回页面时自动拉取。
- 网络要求：只需要 `api.github.com` 可访问（国内一般可直连，无需代理）。
